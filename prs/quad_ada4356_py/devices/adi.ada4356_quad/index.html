ada4356_quad

Quad ADA4356 synchronized capture with AXI TDD controller.

adi.ada4356_quad.ad9517_delay_estimate_ps(ramp, fraction)

Fine-delay estimate for an AD9517 output, from the datasheet formula.

class adi.ada4356_quad.ada4356_quad(uri='')

Bases: _ada4356_alignment

Quad ADA4356 with TDD-synchronized DMA capture.

TDD channel mapping (set at block-design level):

ch0 → trig_fmc_out (external laser / trigger output) ch1 → DMA-A sync ch2 → DMA-B sync ch3 → DMA-C sync ch4 → DMA-D sync

All four DMAs start capturing on the same TDD frame cycle so the sample streams are aligned to within one adc_clk period (8 ns).

parameters:
uri: type=string

Optional parameter for the URI of IIO context with the Quad ADA4356.

bypass_clock_delays()

Put all four ADC clocks back on the undelayed path (firmware state).

property clock_delay

Fine delay last written per channel by this object (None = never written).

Each entry is {‘enabled’, ‘ramp’, ‘fraction’, ‘estimate_ps’}. A reboot restores the firmware state: all bypassed.

clock_sync()

AD9517 soft sync: realigns every divider, briefly stopping all ADC clocks.

property filter_mode

Per-channel FREQ_SEL filter, as a dict keyed by A..D.

property filter_mode_available

FREQ_SEL settings the driver accepts, named after the pin level.

property gain_mode

Per-channel transimpedance, as a dict keyed by A..D.

property gain_mode_available

Transimpedance settings the driver accepts, e.g. [‘133k’, ‘11k’, ‘4k54’].

rx()

Capture one synchronized buffer from all four channels.

Once calibrate_alignment() has run, the per-boot offset is taken out here, so the four arrays share a sample index.

returns: type=list of numpy.array

One array per channel, [A, B, C, D], each rx_buffer_size long.

Raises:

ExceptionGroup: If the capture failed on one or more channels.

property rx_buffer_size

Number of samples per capture per channel.

rx_raw()

One synchronized capture with no alignment applied.

Pair with apply_alignment() to get a corrected/uncorrected A/B from the same acquisition. Two separate rx() calls only compare if the stimulus repeats shot to shot, which a free-running generator does not.

returns: type=list of numpy.array

One raw array per channel, [A, B, C, D], as passed to apply_alignment().

Raises:

ExceptionGroup: If the capture failed on one or more channels.

property sampling_frequency

ADC sample rate (Hz), read from channel A.

set_clock_delay(channel, fraction, ramp=57, enable=None)

Delay one ADC’s sample clock with the AD9517 fine delay (adds delay only).

enable defaults to fraction > 0; enable=True with fraction 0 routes the clock through the delay block, which alone adds ~0.4-0.5 ns (measured 2026-10-19). Raises ValueError above AD9517_DELAY_SAFE_PS. A delayed channel’s tone skew goes up (it reads earlier); its LiDAR ‘d vs A’ goes down.

set_clock_phase(pair, offset, sync=True)

Divider phase offset for a clock pair: ‘AB’ (OUT4/5) or ‘CD’ (OUT6/7).

One step = one 250 MHz divider-input cycle = 4 ns. Takes effect only on a sync, which restarts all four ADC clocks – check ‘frame align:’ in dmesg afterwards.
